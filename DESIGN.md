# Design notes

- [Send-side residency](replication/DESIGN.md#send-side-residency): every non-resident receives current stubs; copies and on-demand reads never promote them to full records.

- [A clone copies filesystem-only applications as the leader packaged them](cloneNode/DESIGN.md#a-clone-copies-filesystem-only-applications-as-the-leader-packaged-them): `node_modules` included from a leader that streams it (5.2.3+ over HTTP); an application it cannot copy keeps the clone Unavailable and uncloned.
- [Removed-origin history](replication/DESIGN.md#removed-origin-history): membership removal preserves audit history, origin mappings and resume cursors; retention purges eligible segments independently.
- [Replication base-copy compatibility](replication/DESIGN.md#base-copy-peer-safety): reported 5.x peers receive historical copies; v4 and unidentified peers retain baseline verification.
- [A release cherry-pick skips a change its branch already has (`workflows/cherry-pick-patch.yml`, `.github/scripts/change-landed.sh`)](.github/DESIGN.md#a-release-cherry-pick-skips-a-change-its-branch-already-has-workflowscherry-pick-patchyml-scriptschange-landedsh) — skip only when one pick of the PR's whole net change would be empty; replaying a landed PR commit by commit conflicts instead.
- [Release backport verification](scripts/DESIGN.md#release-backport-verification): milestone targeting and the publication gate.
- [Analytics CPU profiling: one-period sampling window before each capture, and the `profiler-sampling` marker for the `utilization` samples it inflates](analytics/DESIGN.md)
- [The release tarball bundles the locked JavaScript tree, never a host binary](build-tools/DESIGN.md#the-release-tarball-bundles-the-locked-javascript-tree-never-a-host-binary-build-prosh): core's bundler with pro's native roots unbundled, the dev/prod declaration rule, and what still floats.
- [A core sync warns when it drops content the committed pointer has](build-tools/DESIGN.md#a-core-sync-warns-when-it-drops-content-the-committed-pointer-has-sync-coresh-core-sync-guardsh): the sync always proceeds; `core-sync-guard.sh`'s warning (dropped commits and diffstat) leads the Sync Core PR body; detection is the seam test and the cluster shards, prevention is at the merge step.
- [A YCSB trend point is published only from a turbo-off host](benchmarks/ycsb/DESIGN.md#a-trend-point-is-published-only-from-a-turbo-off-host): the bench runner owns turbo (off per job, on when idle); the nightly checks sysfs itself and skips the publish when the CPU was not at base clock.
- [A marker-free PR is green only if every submodule pointer it moves is settled (`workflows/companion-check.yaml`)](.github/DESIGN.md#a-marker-free-pr-is-green-only-if-every-submodule-pointer-it-moves-is-settled-workflowscompanion-checkyaml): settle branch is the base-named submodule branch else its default; patchless file entries are decided by the head tree; unreadable is pending.
